# TagBatchEditor（曲タグ一括編集ツール）

Bandcamp などからダウンロードした曲は、アーティスト名・トラック番号・曲名などが
曲タイトルやファイル名に詰め込まれていることがよくあります。

このツールは、その文字列を **テンプレート** で分解して、複数の曲のタグをまとめて書き換えます。

```
Supire - Howling
        ↓  テンプレート: {アーティスト} - {タイトル}
タイトル: Howling / アーティスト: Supire / 作曲者: Supire
```

## できること

- タイトル・アルバム・アーティスト・アルバムアーティスト・作曲者・ジャンル・作詞者・
  トラック番号・ディスク番号・年・コメント・**ファイル名** をまとめて書き換え
- フォルダを複数まとめて読み込める（Ctrl / Shift + クリックで複数選択）
- 読み取り元は「今のタイトルタグ」か「ファイル名」を選択
- 書き込む前にプレビューで結果を確認できる
- 書き換え前の内容を自動でバックアップし、ボタン一つで元に戻せる（ファイル名の変更も戻せる）
- よく使うテンプレートをプリセットとして保存できる
- 対応形式: FLAC / MP3 / M4A / OGG / Opus / WAV / AIFF

## ダウンロードと起動

### exe 版（おすすめ・Windows）

1. [Releases](../../releases) から `TagBatchEditor.exe` をダウンロード
2. ダブルクリックで起動

初回に「Windows によって PC が保護されました」と表示された場合は、
「詳細情報」→「実行」を押してください（個人が作った署名なしのアプリのため表示されます）。

### Python で動かす場合

```
pip install mutagen
python tag_batch_editor.py
```

拡張子を `.pyw` に変えると、ダブルクリックで黒い画面を出さずに起動できます。

## 使い方

1. 「フォルダを追加」または「ファイルを追加」で曲を読み込む
   （「フォルダを追加」では Ctrl / Shift を押しながらクリックで複数のフォルダを選べます）
2. **① 分解のルール** で、読み取り元とテンプレートを決める（プリセットからも選べます）
3. **② 各プロパティに入れる内容** で、取り出した値をどの項目に入れるか決める
4. **③ プレビュー** で結果を確認（赤い行はルールに合わないので書き換えません）
5. **④ 適用** で書き込み

### テンプレートの書き方

| 書き方 | 意味 |
|---|---|
| `{名前}` | 文字を取り出す（名前は自由。`{アーティスト}` `{a}` など） |
| `{名前#}` | 数字だけを取り出す（トラック番号・ディスク番号向け） |
| `{*}` | その部分を読み飛ばす |
| それ以外 | 区切り文字。テンプレートに空白を書いた所は、空白が必要です |

例:

| 元の文字列 | テンプレート |
|---|---|
| `Supire - Howling` | `{アーティスト} - {タイトル}` |
| `作曲者 - 1-03 - 曲名` | `{アーティスト} - {ディスク#}-{トラック#} - {タイトル}` |
| `Artist - Album - 07 Track` | `{アーティスト} - {アルバム} - {トラック#} {タイトル}` |

### 各プロパティ欄の書き方

| 書き方 | 意味 |
|---|---|
| 空欄 | 変更しない |
| `{名前}` | テンプレートで取り出した値を入れる（同じ値を複数の欄に入れてもOK） |
| 普通の文字 | 全曲に同じ値を入れる（例: ジャンル欄に `Electronic`） |
| 組み合わせ | `{トラック} - {タイトル}` のように書ける |
| `<削除>` | そのタグを消す |

## 注意点

- 大量の曲に適用する前に、数曲で試すことをおすすめします
- **WAV** はタグの仕組みが2種類あり、両方に書き込みます。
  エクスプローラーで表示される方式には「アルバムアーティスト」「ディスク番号」の項目がなく、
  日本語環境で表示できない文字（à など）は近い文字（a）に置き換えて書き込みます。
  音楽プレーヤー向けのタグには正しい文字で入ります
- 設定とバックアップは `%APPDATA%\TagBatchEditor` に保存されます
  （ツール下部の「設定・バックアップのフォルダを開く」から開けます）

## exe のビルド方法（開発者向け）

```
pip install mutagen pyinstaller
pyinstaller --onefile --windowed --name TagBatchEditor tag_batch_editor.py
```

`dist\TagBatchEditor.exe` ができます。
